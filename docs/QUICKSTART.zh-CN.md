# 第一次使用 Paper Inbox

安装完成后，日常操作都在应用窗口中进行。第一次需要用终端完成环境检查和本机构建。

## 1. 准备软件和文献

| 准备项 | 如何确认 |
| --- | --- |
| macOS 13 或更新版本 | 在苹果菜单的“关于本机”查看 |
| Python 3 | 用于运行本机配置和检查脚本 |
| Git、uv、Poppler | Git 随命令行工具提供，uv 准备 Python 3.11 检索环境，Poppler 提供 PDF 图像工具 |
| Xcode Command Line Tools | 在终端运行 `xcode-select --install`，按系统提示安装；已安装时按提示继续 |
| Codex CLI | 按官方说明安装，然后完成 ChatGPT 账户登录 |
| Zotero | 安装并打开，个人文库中至少有一篇带摘要的论文 |
| Codex 桌面应用 | 用于从“打开 Codex”进入精读任务，安装要求以官方说明为准 |

可通过 [Homebrew](https://brew.sh/zh-cn/) 安装环境；安装好 Homebrew 后运行：

```sh
brew install uv poppler node
npm install -g @openai/codex
```

Zotero 可从[官网下载](https://www.zotero.org/download/)。

Codex 登录使用自己的 ChatGPT 账户及可用的 Codex 额度。在终端运行以下命令，按浏览器提示选择 ChatGPT 账户完成登录，再查看登录状态。向导采用这套账户认证方式。[官方认证说明](https://learn.chatgpt.com/docs/auth)

```sh
codex login
codex login status
```

在 Zotero 的“我的文库”下新建分类，名称为 **AI 文献收藏**。保持 Zotero 打开，首次保存时选中“我的文库”或该分类。

## 2. 运行安装向导

将源码解压到一个自己可以读写、准备长期保留的文件夹。打开“终端”，输入 `cd` 和一个空格，把该文件夹拖入终端窗口，再按回车。后续命令都在这个文件夹中运行。

```sh
./setup.sh
```

按提示选择本机 Zotero 文库位置、精读材料保存位置、每日篇数和界面语言。默认 Zotero 文库为 `~/Zotero/zotero.sqlite`，精读目录为 `~/Documents/Paper Inbox Reading`，每日精选 10 篇。保留默认选项时，直接按回车。

向导会下载固定版本的检索组件、准备 Python 3.11 环境、写入本机配置并构建应用。首次安装需要联网下载依赖。如果只想先填写配置，可运行 `./setup.sh --no-install`，正式使用前再运行完整向导完成依赖安装。

## 3. 检查并打开应用

```sh
./doctor.sh --offline
open "Paper Inbox.app"
```

离线检查用于核对本机配置、文件和依赖，实际联网检索与模型访问由之后的更新和精读验证。若检查列出缺失项，按提示补齐后重新运行。向导构建完成后，也可以在访达中双击生成的 `Paper Inbox.app`。更新源码后，在同一文件夹运行 `./build.sh` 重新构建。

首次打开后等待文献载入，也可点击“更新”。首次下载排序模型、检索论文和生成摘要可能需要较长时间。

## 4. 设置自己的阅读范围

点击侧栏齿轮“设置”，或按 `⌘,`。

- **收藏精读**选择 Codex 模型与推理强度。切换 `gpt-6-astra` 默认使用 `high`，切换 `gpt-6.1-sol` 默认使用 `medium`，可再自行调整。
- **每日文献**选择 1–50 篇，并启用 arXiv、bioRxiv、Journals 中的一个或多个来源。
- **分类**可从旁边的官方说明了解具体范围，多个 arXiv 或 bioRxiv 分类用 `+` 连接，例如 `cs.AI+cs.LG+q-bio.BM`。
- **选择期刊**打开具体期刊列表，勾选希望检索的期刊。
- **语言**选择中文或 English，点击保存后应用到界面。

点击“保存”。来源和篇数会在下次更新时使用，精读模型与强度用于之后提交的任务。

## 5. 阅读和收藏

选择论文查看摘要。选中文字后按 `⌘C` 复制，在搜索框和设置输入框中按 `⌘V` 粘贴；原生文本控件同时支持 `Ctrl+C/V`。打开链接时点击旁边的小图标。

收藏会立即保留本地星标，并在后台启动精读。可以连续收藏多篇，让任务并行进行。点击“打开 Codex”查看进度或处理任务需要的授权。

精读完成后，主界面保留 Motivation 与 Take-home message。完整报告和阅读材料位于设置的精读目录，也可以在 Codex 任务中查看。报告讲解正文及正文图，末尾给出简短的 Take-home message。

完成阅读的论文会保存到 Zotero 的“AI 文献收藏”。已有条目会去重处理。取消收藏会将对应论文从 Zotero 文库移入回收站，精读报告保留；重新收藏会恢复原条目，不重复精读。程序不会清空回收站。标记已读与收藏分别记录。

## 权限提示与常见问题

**macOS 询问文件访问权限。** 确认正在运行自己安装的 Paper Inbox 后，允许访问所选文库和报告目录。此前拒绝过权限时，在“系统设置 → 隐私与安全性 → 文件与文件夹”检查实际运行应用或终端的权限，再重新打开应用。

**Zotero 询问本地保存权限。** 确认请求来自自己刚触发的 Paper Inbox 操作后，可选择“始终允许”。保存等待确认时，先打开 Zotero，并检查“AI 文献收藏”分类是否存在。

**没有文献或排序未就绪。** 先检查 Zotero 个人文库是否有带摘要的论文，再运行 `./doctor.sh --offline` 检查配置。检索服务暂时不可用时，应用会显示相关状态。

**Codex 任务需要处理。** 点击“打开 Codex”查看原任务，按提示完成登录、授权或处理额度问题。论文访问受阻时，报告会说明实际读到的范围和缺口。

**准备移动或分享文件夹。** 应用的本机配置记录了安装位置，移动后重新运行安装向导和构建。对外分发使用干净的源码包，个人配置、缓存、文库、登录凭据和阅读报告留在本机。

## 自动启动与 Zotero 授权

希望登录电脑后自动更新时，构建完成后运行 `./install-login.sh`。电脑需要已登录并联网；睡眠期间暂停，唤醒后补查。

首次启用收藏同步，保持 Zotero 打开，运行 `./authorize-zotero.sh`，在 Zotero 官方窗口选择“始终允许”。这会允许 Paper Inbox 写入本地文库：精读完成后入库、取消收藏时移入回收站、重新收藏时恢复原条目。程序不清空回收站。授权凭据仅保存在本机 cache，不随源码分享。

## 使用摘要 API

在“设置 → 摘要生成”选择 OpenAI API，选择模型 ID 和推理强度，填入新密钥并保存。密钥仅存 macOS 钥匙串，输入框留空可保留原密钥。收藏精读继续使用独立配置的 Codex 模型。首次读取密钥时，macOS 可能要求确认钥匙串访问；请先解锁电脑。不要把真实密钥提交到 GitHub 或发到聊天中。
