# 论文解读：思想、方法与证据

目标是让用户快速理解一篇论文，并能向别人讲清楚。默认采用中文，依次组织为问题定义、Motivation、Methods、Results、逐图精读和 take-home message 六部分。逐图精读以正文 Figures 为主。每张图先概括整体“是什么、为什么”，再按原始标签逐一简洁说明每个子图的“是什么、为什么”，问题定义与 Motivation 各 1–2 句，Methods 交代核心输入、步骤与输出，Results 提炼 2–3 条发现，每个子图通常 1–2 句，最后以 2–3 句 take-home message 收束。

执行前阅读 [论文解读方法论](references/paper-reading-methodology.md)，按其中的证据标准与输出结构完成解读。该文件也可作为独立 Markdown 指令用于其他项目或工具。

用户本次明确指定的语言、篇幅或分析范围优先于默认结构。若只问某张图或一个概念，直接回答该范围，不强制输出整套六部分。

优先使用用户提供的附件、文件或链接；没有可识别的论文时，请用户提供论文文件、标题、DOI 或链接，不根据项目名称或历史记录猜测目标。需要读取 PDF、网页或图像时使用当前可用工具；本技能不绑定特定服务。默认在聊天中交付，不自动创建页面、幻灯片或修改原始论文。

正文图范围按论文的正式分类判断。必要时可阅读与主要方法或结论密切相关的 SI、附录与 Extended Data，并将有关信息简短融入对应解释；无需逐图遍历这些补充材料。完整阅读后的方法名称提取仅在自动化或已授权的会话重命名需要时作为内部步骤，详见方法论；不在读者报告末尾附加名称元数据或核对清单。
